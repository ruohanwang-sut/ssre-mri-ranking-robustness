# Data Availability

The volume-level metrics, paired statistical results, figure source data,
analysis code and derived qualitative image arrays supporting this study
are publicly available at https://github.com/ruohanwang-sut/ssre-mri-ranking-robustness.
The original MRI acquisitions are from the fastMRI dataset and are available
from https://fastmri.med.nyu.edu/ subject to the provider's application and
access terms; they are not redistributed in this repository. Third-party
checkpoint sources and frozen identities are documented in the repository.
